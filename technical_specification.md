# Техническое задание
## Десктоп/TUI приложение для чтения электронных книг

---

### 1. Общие сведения

| Параметр | Значение |
|----------|----------|
| **Название проекта** | Определяется разработчиком |
| **Целевая платформа** | Linux |
| **Тип приложения** | TUI (Terminal User Interface) |
| **Язык разработки** | TypeScript |
| **Среда выполнения** | Node.js |
| **Целевая аудитория** | Энтузиасты терминала, power users |
| **Лицензия** | MIT |
| **Язык интерфейса** | Английский |

---

### 2. Цель и назначение

Разработать TUI-приложение для чтения электронных книг в форматах FB2 и EPUB с акцентом на:
- Максимальное соответствие оригальному форматированию книг
- Интуитивное vim-like управление
- Расширяемую систему тем оформления
- Полноценную библиотеку с метаданными

---

### 3. Поддерживаемые форматы

| Формат | Поддержка | Примечания |
|--------|-----------|------------|
| **FB2** | Полная | Включая fb2.zip (архивы ZIP с FB2 внутри) |
| **EPUB** | Полная | EPUB 2.x / 3.x, включая вложенные стили CSS |

**Не поддерживаются:** PDF, DJVU, MOBI, AZW3, CBR/CBZ и прочие форматы.

---

### 4. Функциональные требования

#### 4.1. Режим библиотеки (Library View)

**Отображение:**
- Компактные карточки книг в библиотеке
- Информация на карточке: название, автор(ы), прогресс чтения (%), статус
- Детальный вид книги по нажатию Enter: обложка (через графический протокол терминала), полные метаданные, аннотация

**Метаданные (извлекаются из файла):**
- Название книги
- Автор(ы)
- Серия и номер в серии
- Жанр(ы)
- Аннотация
- Обложка

**Операции:**
- Добавление книги в библиотеку: клавиша `s` (save) — сохраняет открытую книгу в библиотеку
- Открытие книги из файловой системы: клавиша `o` (open) — вызывает `xdg-open` для выбора файла через системный файловый менеджер
- Удаление книги из библиотеки (только из базы данных, файл на диске не трогается)
- Группировка по сериям с сортировкой по номеру в серии
- Сортировка: по названию, автору, дате добавления, прогрессу чтения
- Фильтрация и поиск по библиотеке: по названию, автору, серии, жанру

#### 4.2. Режим чтения (Reader View)

**Отображение контента:**
- По умолчанию: максимально точное отображение оригинального форматирования
- Поддерживаемые элементы: заголовки (H1–H6), абзацы, списки (нумерованные/маркированные), таблицы, цитаты, врезки, жирный/курсив/подчёркнутый текст
- Изображения: отображение обложек и иллюстраций через графический протокол терминала (Sixel / Kitty Graphics Protocol / iTerm2 inline images)
- Упрощённый режим: переключаемый опция, отключает сложное форматирование, оставляет только текст, жирный/курсив, заголовки

**CSS из EPUB:**
- Пользовательский выбор: «Уважать CSS издателя» / «Игнорировать CSS издателя»
- При уважении CSS: интерпретировать ключевые правила (цвета, выравнивание, отступы), игнорировать неподдерживаемые
- При игнорировании: применять внутреннюю типографику приложения

**Навигация:**
- Постраничная навигация
- Навигация по главам (оглавление)
- Навигация по закладкам (с метками)
- Текстовый поиск по текущей книге:
  - Подсветка результатов
  - Переход между результатами (`n` / `N`)
- Переход к номеру страницы
- Автоматический возврат к месту последнего чтения при открытии книги

**Закладки:**
- Создание закладки на текущей позиции с пользовательской меткой (текстовой)
- Различные метки для закладок (пользователь задаёт текст метки)
- Просмотр списка закладок книги
- Переход к закладке
- Удаление закладки

**Прогресс и статистика:**
- Отображение прогресса чтения в процентах
- Статистика: время чтения, прочитанные страницы

#### 4.3. Типографика

Настраиваемые параметры (через конфигурацию):
- Ширина строки (measure)
- Межстрочный интервал
- Отступы абзацев
- Перенос слов (hyphenation) — при наличии словаря
- Выбор шрифта (если терминал поддерживает, через CSS font-family или терминальные настройки)
- Поддержка ligatures (через терминал)

#### 4.4. Темы оформления

**Встроенные темы:**
- Monokai
- Dracula
- Ayu (Dark / Light)
- GitHub (Dark / Light)
- Дополнительно: Gruvbox (Dark / Light), Nord, Solarized (Dark / Light), One Dark, Catppuccin

**Характеристики тем:**
- Каждая тема определяет цвета для: фона, текста, заголовков, акцентов, выделения, панелей, статусной строки, подсветки поиска
- Поддержка тёмных и светлых вариантов
- Возможность создания пользовательских тем через конфигурацию

#### 4.5. Управление

**Модель:** vim-like

**Базовые клавиши (по умолчанию):**
| Клавиша | Действие |
|---------|----------|
| `j` / `k` | Прокрутка вниз / вверх |
| `h` / `l` | Навигация по элементам интерфейса |
| `gg` | Переход к началу |
| `G` | Переход к концу |
| `/` | Поиск по книге |
| `n` / `N` | Следующий / предыдущий результат поиска |
| `o` | Открыть книгу из файловой системы (через `xdg-open`) |
| `s` | Сохранить открытую книгу в библиотеку |
| `b` | Добавить закладку |
| `B` | Список закладок |
| `t` | Оглавление (таблица содержимого) |
| `i` | Информация о книге (метаданные) |
| `?` | Справка по горячим клавишам |
| `q` | Выход / закрыть текущий вид |
| `:` | Командная строка |

**Настройка клавиш:**
- Все горячие клавиши переопределяются через конфигурационный файл
- Формат: `{ "action": "open_file", "key": "Ctrl+o" }`
- Проверка конфликтов при загрузке конфига

### 5. Нефункциональные требования

#### 5.1. Производительность

- Загрузка книги целиком в память при открытии — приемлемо
- Время открытия книги до 10 МБ: < 1 секунды
- Время открытия книги до 50 МБ: < 3 секунды
- Прокрутка текста: без задержек, 60 FPS эмуляции
- Поиск по книге: индексация при первом открытии, последующий поиск мгновенный

#### 5.2. Надёжность

- При повреждённых файлах (невалидный XML в FB2, битый ZIP в EPUB): показывать предупреждение с описанием ошибки, предлагать попытаться открыть (best-effort)
- Приложение не должно падать при некорректном вводе
- Graceful degradation: если терминал не поддерживает графические протоколы — изображения скрываются с уведомлением

#### 5.3. Хранение данных

**База данных:** SQLite, расположена в `~/.config/<app-name>/library.db`

**Хранимые данные:**
- Метаданные книг в библиотеке
- Прогресс чтения (позиция в книге, процент)
- Закладки (позиция, метка, дата создания)
- Статистика чтения (время, страницы)
- История последних открытых книг

**Конфигурация:** `~/.config/<app-name>/config.toml` (TOML-формат)

**Содержимое конфига:**
- Тема оформления
- Горячие клавиши
- Настройки типографики
- Параметры отображения (упрощённый режим, уважение CSS)
- Путь к базе данных (опционально)

#### 5.4. Архитектура

**Рекомендуемый стек:**
- TUI-фреймворк: `blessed` или `react-blessed` (или современная альтернатива: `ink` для React-based TUI)
- Парсер FB2: `fast-xml-parser` или `xml2js`
- Парсер EPUB: `adm-zip` / `node-stream-zip` + `fast-xml-parser`
- База данных: `better-sqlite3`
- Конфигурация: `toml`
- Обработка изображений: `sharp` (для ресайза) + `sixel` / `kitty-node` (для вывода)
- Аргументы CLI: `commander` или `yargs`

**Структура модулей:**
```
src/
├── cli/              # Обработка аргументов командной строки
├── config/           # Загрузка и валидация конфигурации
├── db/               # SQLite-слой, миграции
├── formats/          # Парсеры FB2 и EPUB
│   ├── fb2/
│   └── epub/
├── renderer/         # Рендеринг контента в TUI
│   ├── css-engine/   # Интерпретация EPUB-CSS
│   ├── images/       # Вывод изображений в терминал
│   └── typography/   # Настройки типографики
├── themes/           # Система тем
├── tui/              # Компоненты интерфейса
│   ├── library/      # Вид библиотеки
│   ├── reader/       # Вид чтения
│   ├── bookmark/     # Управление закладками
│   └── help/         # Справка
├── bookmarks/        # Логика закладок
├── search/           # Поиск и индексация
└── utils/            # Утилиты
```

#### 5.5. CLI-интерфейс

```bash
# Запуск с открытием библиотеки
<app-name>

# Открыть конкретный файл
<app-name> /path/to/book.fb2
<app-name> /path/to/book.epub

# Открыть библиотеку
<app-name> --library

# Указать тему
<app-name> --theme dracula

# Показать версию
<app-name> --version

# Показать справку
<app-name> --help
```

**Ассоциация с MIME-типами:** желательна (`.desktop`-файл для регистрации `application/x-fictionbook+xml` и `application/epub+zip`), но не обязательна для MVP.

### 10. Критерии приёмки

1. Приложение устанавливается через `npm install -g` и запускается командой
2. Открывает FB2 и EPUB файлы, включая архивированные FB2
3. Корректно отображает структуру документа (заголовки, списки, абзацы)
4. Сохраняет прогресс чтения между сессиями
5. Поддерживает создание закладок с метками и навигацию по ним
6. Реализован поиск по книге с подсветкой
7. Доступно не менее 8 встроенных тем (тёмных и светлых)
8. Управление полностью vim-like с возможностью переопределения клавиш
9. Покрытие тестами ≥ 80%
10. Документация позволяет новому пользователю начать чтение за 5 минут

---

### 11. Ограничения и допущения

- Приложение работает только в терминалах с поддержкой Unicode и 256+ цветов
- Отображение изображений требует терминала с поддержкой Sixel, Kitty Graphics Protocol или iTerm2 inline images; в остальных случаях изображения скрываются
- Производительность на книгах > 100 МБ не гарантируется (загрузка в память)
- Синхронизация между устройствами не входит в скоуп MVP
- OPDS-каталоги — потенциальная фича следующих итераций
- Экспорт/импорт данных — потенциальная фича следующих итераций
