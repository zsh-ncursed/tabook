# Чеклист ручной проверки в терминале

## 1. Command Palette (Ctrl+P)

- [ ] Открыть палитру — пустой запрос показывает только команды
- [ ] Ввести название книги — книги появляются вместе с командами, отсортированы по релевантности
- [ ] Ввести имя автора — книги автора находятся
- [ ] Ввести название серии/жанра — книги находятся
- [ ] Проверить подсветку: буквы запроса в title подсвечены accent-цветом
- [ ] Стрелки ↑/↓ — курсор движется, контейнер скроллится
- [ ] Enter на команде — команда выполняется
- [ ] Enter на книге — книга открывается (появится спиннер)
- [ ] Esc — палитра закрывается без действия
- [ ] Список пуст при несовпадении — показывается «no matching commands or books»
- [ ] Палитра центрирована по ширине экрана

## 2. Книга при открытии — спиннер

- [ ] Открыть книгу из библиотеки (Enter на книге) — наlarge файлах появится «⠋ Opening book…»
- [ ] Спиннер исчезает после загрузки, книга открывается
- [ ] Если парсинг падает — спиннер исчезает, появляется уведомление об ошибке

## 3. Delete Confirm — новая модалка

- [ ] В библиотеке нажать `x` или `d` на книге — появляется модалка подтверждения
- [ ] Модалка **центрирована** по экрану (не прижата к левому краю)
- [ ] Модалка имеет **красный round-бордер**
- [ ] Заголовок: «Delete book» или «Remove from library»
- [ ] Текст содержит название книги и описание последствий
- [ ] Футер: `y confirm · esc cancel`
- [ ] `y` / Enter — подтверждает, книга удаляется
- [ ] `n` / Esc — отменяет, возврат к списку

## 4. StatusBar — message

- [ ] Выполнить действие с уведомлением (например `:theme dracula`) — сообщение появляется в status bar
- [ ] Сообщение отображается accent-цветом (отличается от hint)
- [ ] Сообщение автоматически исчезает через ~3.5 сек
- [ ] Во время сообщения hint скрыт (message приоритетнее)

## 5. Модалки — центрирование

- [ ] `:themes` — ThemePicker центрирован
- [ ] `?` (помощь) — HelpView центрирован
- [ ] Book Detail (Enter на книге в библиотеке) — модалка центрирована
- [ ] TOC в ридере — ListModal центрирован
- [ ] Bookmarks в ридере — ListModal центрирован

## 6. Библиотека — общий вид

- [ ] Список книг отображается с карточками (3 строки на книгу)
- [ ] Курсор (▸) и выделение (selection-цвет) консистентны
- [ ] Фильтр `/` — live-фильтрация работает, Esc восстанавливает
- [ ] Аннотация выбранной книги — 3 строки под списком
- [ ] Каверы отображаются слева от карточек (если ueberzugpp/kitty доступны)

## 7. Ридер

- [ ] Книга открывается, контент читается
- [ ] Статус бар: название, страница, прогресс, хинт клавиш
- [ ] `j`/`k`/стрелки — скролл
- [ ] `/` — поиск по книге, `n`/`N` — навигация
- [ ] `:` — командная строка, Tab-completion работает
- [ ] `?` — помощь
- [ ] `i` — InfoModal с метаданными и обложкой
- [ ] Mouse selection (drag) — выделение текста, `y` — копирование

## 8. OPDS

- [ ] Каталоги отображаются списком
- [ ] Enter открывает каталог, загрузка с спиннером
- [ ] `d` — скачивание книги, прогресс в status bar
- [ ] `x` — панель загрузок
- [ ] `c` — возврат к списку каталогов
- [ ] Каверы entries отображаются
