# Backlog

Идеи из аудита фич (сверка предложенного списка с кодовой базой). Документ живой:
пункты отмечаются галочкой по мере реализации и переносятся в `ROADMAP.md`.

## Полностью не реализовано

- [ ] **Подсветка текущей строки в reader** — `ReaderSession.currentLine` уже есть
      (позиция курсора), но строка в рендере не подсвечивается. Сильно помогает
      при чтении, низкая сложность.
- [ ] **Fuzzy-поиск по библиотеке прямо в палитре Ctrl+P** — сейчас палитра
      ищет только по командам (`usage + desc`), а фильтр библиотеки `/` —
      substring (`includes`). Движок `fuzzyMatch` уже в `src/tui/commands.ts` —
      можно переиспользовать для книг (автор/название).
- [ ] **Индикатор режима (normal/insert) в статусбаре** — vim-стиль. Секции
      статусбара сейчас: title/page/percent/search/hint/downloads — режима нет.
- [ ] **История уведомлений** — сейчас `notify` → один toast (`setMessage`),
      хранить последние N и показывать список.

## Частично реализовано (нужно доделать)

- [ ] **Онбординг первой книги** — при пустой библиотеке есть подсказка
      «Attach a folder with `:library add <path>`…», но нет короткого
      «j/k — листать, / — поиск» при первом запуске без библиотеки.
- [ ] **Индикатор прогресса в скроллбаре** — прогресс-бар `█░ + %` в статусбаре
      ридера (`showProgressBar`) и `progressPercent` в карточках книг есть,
      но визуального скроллбара с позицией в процентах нет (ни в списке, ни в
      ридере).
- [ ] **Popover-превью аннотации в карточке книги** — есть `AnnotationPreview`
      (панель под списком для выбранной книги), но это не popover при
      наведении (в терминале hover нет — вопрос UX-подхода).
- [ ] **Discoverability клавиш в палитре** — поиск по имени действия работает
      (fuzzy по usage+desc), но текущие биндинги клавиш в палитре не
      показываются (в haystack биндинги не входят).
