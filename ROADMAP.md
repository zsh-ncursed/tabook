# Roadmap

Статус целей развития tabook. Документ живой: идеи приходят из код-ревью,
обратной связи и планов в `technical_specification.md`; пункты отмечаются
галочкой по мере реализации и переносятся в релизные заметки.

- **v0.3.x** — сделано (контекст для планирования)
- **v0.4.0** — сделано
- **v0.5.2** — сделано (наведение порядка: нативный сканер, один SQL-бэкенд,
  упаковка npm, clippy)
- **v0.6.0** — сделано (TTS: модалка голоса, приоритет плееров, Piper
  опционально, фиксы гонок и утечек)
- **v0.7.0** — в плане (пропорциональные графические шрифты, graphics-режим)
- **v0.5+** — крупные фичи, требующие отдельного проектирования

---

## v0.3.x — сделано

- **OPDS**: пагинация (`p`/`n` + индикатор страницы), поиск из корня каталога
  (OpenSearch discovery на root-ленте), фоновая очередь загрузок с прогрессом
  (панель `x`, отмена, открытие готового), декодирование XML-сущностей в
  шаблонах OSD (баг, найденный на живом Flibusta).
- **UI**: конфигурируемый статусбар (секция `[statusbar]`), поддержка мыши
  (SGR: клик — курсор, дабл-клик — открыть), автотема по фону терминала
  (`auto_theme`, OSC 11, исправлен приём ответа в raw mode).
- **CLI**: `--man` и `--completion bash|zsh` — генерируются из реестров
  команд/клавиш; man-страница и комплиты входят в релизный тарбол и
  устанавливаются PKGBUILD.
- **Релиз**: v0.3.4 — тарбол x64+arm64, CI собирает ассеты, AUR-пакет
  публикуется автоматически (sha256 подставляются workflow'ом).

## v0.4.0 — сделано

- **Command palette** (Ctrl+P, fuzzy-поиск по командам): overlay
  `src/tui/components/CommandPalette.tsx` ищет по usage+desc реестра
  `src/tui/commands.ts` (fuzzy-субпоследовательность), `enter` выполняет
  команду, `esc` закрывает. Доступен во всех трёх вьюхах.
- **Обложки в OPDS-каталогах и списке библиотеки**: карточки книг/записей
  занимают 3 строки с миниатюрой слева (общий модуль раскладки
  `src/tui/listLayout.ts`). Обложки библиотеки извлекаются точечно без полного
  парсинга (`src/formats/cover.ts`), OPDS — по `thumbnailHref` с учётом auth;
  рисуются через `imageLayer` (kitty/ueberzugpp), скрываются при оверлеях.
- **Выделение текста мышью** в читалке (SGR drag, DECSET 1002): `b` — закладка
  с текстом выделения как меткой, `y` — копирование через OSC 52; исправлен
  конфликт распознавания `\x1b[`-чанков мыши как клавиши `[`.
- **Фиксы отображения картинок**: дублирование строк после картинки в kitty
  (placement в save/restore курсора + `C=1`), артефакты при закрытии приложения
  (ueberzugpp убивается при unmount App, kitty delete-all пишется синхронно),
  обложки поверх заголовка «Library» при запуске из шелла (alternate screen:
  `\x1b[?1049h\x1b[2J\x1b[H` на старте, `\x1b[?1049l` на выходе), рестарт
  оверлея после ресайза терминала (ueberzugpp пере-измеряет метрики).
- **Релиз**: v0.4.0 — тарбол x64+arm64, CI собирает ассеты, AUR публикуется
  автоматически.

## v0.5.2 — сделано

- **Скан библиотеки на нативных парсерах метаданных**: горячий путь сканера
  переведён с fast-xml-parser на Rust fast-paths (`parseBookMetadata`-гейт),
  ~5× на парсинге (2.5 → 0.6 мс/книгу на корпусе 60 FB2 × 49 KB); батчинг с
  yield и прогрессом не изменились. TS-парсеры остаются fallback'ом.
- **Один SQL-бэкенд**: better-sqlite3 бэкенд удалён (db.ts 1344 → 657 строк),
  схема и миграции живут только в Rust (`db.rs`) — устранён дрейф двойной
  поддержки. `LibraryDb` при недоступном биндинге падает с понятной ошибкой и
  подсказкой `npm run build:native`; better-sqlite3 остался в devDependencies
  как raw-SQL-инструмент тестов.
- **Фикс `npm run dev`**: tsx применял `paths`-маппинг tsconfig к рантайм-
  `require()`, биндинг грузился как пустой стаб из `.d.ts` и каждый
  `if (native)` звал несуществующую функцию. Загрузчик валидирует модуль
  (настоящий биндинг экспортирует `hello()`) и падает на TS-fallback с
  диагностикой.
- **Упаковка npm**: `verify:npm` в CI (pack → install → смоук CLI + парсинг +
  цикл БД), `prepare-npm.mjs` вендорит биндинг в тарбол, `setup-hooks.mjs`
  не hijack'ает git-хуки потребителя. Бандл больше не содержит better-sqlite3.
- **Качество Rust**: clippy pedantic 181 ошибка → 0 (реальные находки: regex в
  циклах, case-sensitive матчинг `.fb2`-энтрий в zip, дубликаты match-arms;
  «длинные функции» — точечные allow с rationale о паритете). `clippy -D
warnings` и `cargo fmt --check` — настоящие гейты CI (continue-on-error
  снят).
- **Релиз**: v0.5.2 — тарбол x64+arm64, CI/Release/AUR-пайплайн зелёный.

## v0.6.0 — сделано

- **TTS: настройка голоса через модалку + скачивание голосов Piper** —
  `:tts config` открывает `TtsConfigModal` (движок, голос, rate, pitch, follow,
  apply/cancel с персистом в config.toml). Список Piper-голосов тянется с
  HuggingFace (hf-mirror, кеш на 24ч), выбранный голос докачивается
  стрим-скачиванием с прогрессом и сразу используется. Pitch добавлен в
  `[tts]` конфиг и применяется в espeak-ng (`-p`); piper его не поддерживает
  (помечено в capabilities).
- **Приоритет плееров TTS** — `ffplay` теперь первый (ffmpeg есть почти
  везде: серверы, контейнеры, Termux), `paplay` и `aplay` — fallback'и.
- **Piper — опциональная зависимость пакета.** Убран из `depends`, объявлен
  в `optdepends` + подсказка в `post_install`. При `:tts` без установленного
  движка показывается уведомление с командой установки (AUR/pipx) вместо
  сырого `ENOENT` в статус-баре; проверка движка вынесена в pre-flight
  (`TtsManager.check()`) — до синтеза, а не после упавшего чанка. Пути к
  бинарю: `resolvePiperBin()` перебирает `[tts] command`, `TABOOK_TTS_COMMAND`,
  `piper`/`piper-speak` в `PATH` и типичные места pipx/venv/standalone.
- **Устранение гонок и утечек в TTS.** `stopping`-флаг заменён на монотонный
  счётчик поколений: раньше он сбрасывался синхронно внутри `stop()`, и все
  async-гварды были мёртвым кодом — стоп во время синтеза включал звук, а
  `:tts` + быстрый `:tts stop` запускали озвучку после стопа. Временные
  wav-файлы регистрируются и чистятся на каждом `stop()`, а не только при
  выходе (раньше `tmpFiles` оставался пустым, и каждый чанк оставлял файл
  в `/tmp` навсегда).

## v0.6.1 — сделано

Корректирующий релиз: одно поведение, одно исправление.

- **Мерцание экрана во время озвучки (`:tts`).** Корневой `Box` в `App.tsx`
  несёт `minHeight={height}` — намеренно, без него счётчик строк `logUpdate`
  устаревает и после закрытия модалки на экране остаются хвосты старого кадра
  (строки книги, рамки диалогов). Побочный эффект: `minHeight` всегда выполняет
  условие `outputHeight >= rows` в Ink, поэтому отрисовка идёт по ветке
  `clearTerminal` (полное стирание экрана) на **каждом** рендере, а инкрементальный
  `log-update` не используется вовсе. В покое это незаметно — кадр
  перерисовывается только по нажатию клавиши. Озвучка добавляет собственный
  источник ре-рендеров (брайль-спиннер `TtsIndicator` на `setInterval` 80 мс плюс
  обновление статуса и караоке на каждый чанк), то есть полная очистка экрана
  происходила 12–16 раз в секунду — это и было мерцание. Исправление: вывод Ink
  обёрнут в synchronized output (DECSET 2026, `src/tui/syncOutput.ts`), терминал
  применяет такой кадр атомарно. `minHeight` и защита от хвостов не тронуты;
  терминалы без поддержки 2026 игнорируют режим и работают как раньше.

## v0.7.0 — пропорциональные графические шрифты (в плане)

Готово по ТЗ `tabook-graphics-fonts-tz.md` (v1.2, согласовано 2026-10-03).
Следующий спринт. Цель — опциональный graphics-режим чтения с
пропорциональными TTF/OTF, не ломая mono-TUI, TTS, поиск, выделение и
навигацию.

### Ключевое

- [ ] **Второй бэкенд рендера `graphics`** (Kitty protocol) рядом с mono
      (Ink/ANSI). Переключение `:set render mono|graphics|auto` на лету.
- [ ] **Загрузка TTF/OTF** произвольных, плюс dot-системная библиотека шрифтов.
- [ ] **Navigation/аннотация API**: единый `offset ↔ cluster ↔ rect` mapping —
      основа для mouse selection, копирования (OSC 52 / arboard), подсветки.
- [ ] **Настройки через TOML и команды** (`:font`, `:font-size`, `:line-height`,
      `:hyphenation`, `:justify`, `:font-fallback`).
- [ ] **Профили типографики** — экспорт/импорт сразу в основном объёме.

### Архитектурно

- [ ] Rust: `text/`, `font/`, `shape/`, `layout/`, `render/`, `highlight/`,
      `cache/`, `profile/` + napi_api.
- [ ] TS: `ui/components/GraphicsView.tsx`, `MonoView.tsx`; hooks
      (`useMouse`, `useSelection`, `useKittyGraphics`, `useViewport`);
      services (`renderBridge`, `highlightBridge`, `profileBridge`,
      `packageBridge`).
- [ ] Два бэкенда, общий mapping, ленивое кэширование, dirty-инвалидация,
      opt-in.

### Пайплайн рендера

- [ ] render_viewport → диск кэш → строки → layout (shaping+fallback+переносы)
      → raster (атлас+swash) → composition → PNG → диск → Kitty emitter.
- [ ] Dirty-инвалидация по `RowCacheKey` (шрифт/кегль/line-height/ресайз/
      подсветка/тема).

### Кэши

- [ ] Mem: glyph atlas, layout строк/страниц, отрендеренные строки, PNG
      viewport — LRU.
- [ ] Disk: `~/.cache/tabook/render/`, 500 МБ LRU, TTL 30 дней.
- [ ] Prefetch: 2 страницы вперёд/назад + 1–2 абзаца для TTS.

### Kitty graphics

- [ ] Placements: viewport (скролл) + построчные (dirty-подсветка).
- [ ] `a=T/p/d`, `i=`, `p=`, `f=100` PNG. Sixel — нет.
- [ ] Fallback: ueberzugpp для картинок, mono для текста.

### Мышь и выделение

- [ ] SGR mouse mode (`\x1b[?1000/1002/1006h`), click/double/triple/drag/
      shift+drag.
- [ ] Копирование OSC 52 (лимит 8 КБ, предупреждение) + arboard fallback.

### Подсветка

- [ ] Единый слой `HighlightLayer` для всех типов: TTS / search / selection /
      bookmark.
- [ ] `intersects_row`, `hash_for_row` → dirty-инвалидация строк.
- [ ] Приоритет отрисовки: selection → search match → search active →
      bookmark → TTS sentence → TTS current word.

### Шрифты

- [ ] Основной — Literata/Serif; fallback-цепи: основной → script-specific
      (CJK, Arabic) → emoji → system.
- [ ] VF → 3 фиксированных инстанса (Regular 400, Bold 700, Italic 400 italic;
      synthetic oblique если нет оси).
- [ ] Не хранить шрифты в репо; опциональная установка (пакеты/down).

### Настройки, конфиг, профили

- [ ] Блок `[render]`, `[font]`, `[font.fallback]`, `[font.packages]`,
      `[layout]`, `[cache]`, `[highlight]` в TOML.
- [ ] Команды `:set render`, `:font`, `:font-size`, `:line-height`,
      `:hyphenation`, `:justify`, `:font-fallback`, `:profile ...`.
- [ ] Встроенные пресеты: `novel`, `poetry`, `technical`, `cjk`, `dyslexia`.
- [ ] Экспорт/импорт профилей, валидация `schema_version`.

### Производительность и тесты

- [ ] Метрики: первый рендер <150 мс, скролл mem <16 мс, disk <8 мс,
      листание <100 мс.
- [ ] Rust unit: shaping (лигатуры, арабица, деванагари, emoji), mapping,
      atlas, layout, highlight, VF-инстансы, профили.
- [ ] Интеграция: FB2 → 100 страниц без утечек, ресайз ×50, TTS+подсветка+
      скролл, дисковый кэш (hit/miss/LRU/TTL).
- [ ] Терминалы: kitty, WezTerm, Ghostty, Konsole; fallback xterm/foot.
- [ ] Путь по этапам ТЗ (1–7), критерии готовности из раздела 22.

## v0.5.0 — цели

### Топ-3 приоритета

- [ ] **Качество в CI**: постоянный pty-смоук-тест TUI (клавиши, SGR-мышь,
      OSC 11 — харнесс собран вручную при проверке v0.3.4). Закрывает правило
      AGENTS.md «TUI needs real terminal» и долги из ревью. (`cargo fmt check`
      уже добавлен в CI в v0.5.2.)

### Полный список идей

**Читалка**

- [ ] **Статистика чтения** — сессии/история уже пишутся в БД, нужна только
      вью: время за книгу, streak, % прочитанного. Низкая сложность.
- [ ] **Копирование текста в буфер** — xclip/xsel/wl-paste уже интегрированы,
      нужен selection-режим. Для цитирования и выписок.
- [ ] **Экспорт закладок в Markdown** (Kindle-style) — закладки с метками и
      позициями уже в БД.
- [ ] **Настройки типографики** — расширить существующую секцию `[typography]`:
      размер шрифта, интерлиньяж. Пункт из техспецификации.

**Библиотека**

- [ ] **Поиск по библиотеке** — fuzzy по названию/автору/жанру. Пункт из
      техспецификации.
- [ ] **Группировка по сериям** — поля `series`/`series_number` уже в схеме БД.
- [ ] **Экспорт/импорт библиотеки** (JSON) — бэкап и перенос.
- [ ] **Виртуальный скролл** — для библиотек >10k книг.

**OPDS**

- [ ] **Параллельные загрузки (2–3) + resume по Range** — очередь сейчас
      строго последовательная; докачка после обрыва.
- [ ] **Управление каталогами в TUI** — добавить/удалить/отредактировать
      (сейчас — только пресид в БД).

**UX**

- [ ] **Смена темы по времени суток** — расширение `auto_theme` (день/ночь).
- [ ] **Live-`set` конфига** — `:set statusbar.right=[...]` с персистенцией,
      без ручного редактирования TOML.

**Качество**

- [ ] **Бенчмарк парсинга TS vs Rust** — паритет есть, добавить замеры, чтобы
      ловить регрессии производительности.
- [ ] **Golden-тесты рендера** — пункт №1 из код-ревью.

## v0.5+ — крупные фичи

- **Синхронизация прогресса между устройствами** (WebDAV / self-hosted) — в
  техспецификации явно «out of MVP».
- **CSS-движок для EPUB** — самый большой пункт техспецификации.
- **OPDS 2.0** — сейчас поддерживается только Atom 1.x.
