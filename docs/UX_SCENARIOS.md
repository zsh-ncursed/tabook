# UX-сценарии tabook: матрица действий и сквозные сценарии

Документ — основа для код-ревью UI и интеграционных тестов (`src/tui/App.ux.test.tsx`).

Два уровня:

1. **Матрица действий** — для каждого состояния UI (экран / режим / модалка):
   доступные действия, переход, обратная связь пользователю.
2. **Сквозные сценарии (journeys)** — пути по матрице, отражающие реальное
   использование: пользователь смешивает экраны (чтение → библиотека → OPDS →
   чтение), и на каждом шаге должен понимать, что происходит.

Обозначения обратной связи: `[notify]` — сообщение в статус-баре (исчезает
через ~3.5 с), `[frame]` — изменение кадра, `[spinner]` — индикатор загрузки,
`[status]` — секция статус-бара (режим/прогресс/загрузки).

## Часть 1. Матрица «состояние × действие × переход × отклик»

### 1.1. Library — `normal`

Клавиши по умолчанию (keymap): `j/k` — курсор, `enter` — карточка, `o` —
открыть файл, `/` — фильтр, `:` — команда, `d/D` — удалить, `R/C` —
Recent/Continue, `?` — help, `q` — выход, `ctrl+p` — палитра.

| Действие              | Клавиша/команда                            | Переход                                    | Отклик                                                      |
| --------------------- | ------------------------------------------ | ------------------------------------------ | ----------------------------------------------------------- |
| Курсор вниз/вверх     | `j`/`k`, стрелки                           | остаёмся (курсор)                          | `[frame]` подсветка строки, никогда не на заголовке серии   |
| В начало/конец        | `gg`/`G`                                   | остаёмся                                   | `[frame]` курсор на первой/последней книге                  |
| Страница вниз/вверх   | `space`/`backspace`, `ctrl+d/u`, PgDn/PgUp | остаёмся                                   | `[frame]` окно списка сдвигается                            |
| Открыть карточку      | `enter`                                    | Library `detail`                           | `[frame]` модалка BookDetail                                |
| Открыть файл          | `o`                                        | reader или path-промпт                     | `[notify] Selecting file…`; picker недоступен → промпт пути |
| Удалить из библиотеки | `d`                                        | Library `confirm-delete`                   | `[frame]` модалка подтверждения                             |
| Удалить файл с диска  | `D`                                        | Library `confirm-delete` (deleteFile=true) | `[frame]` модалка с предупреждением о необратимости         |
| Фильтр                | `/`                                        | Library `filter`                           | `[frame]` промпт, живое сужение списка                      |
| Сортировка            | `:sort <field>` / цикл                     | остаёмся                                   | `[frame]` `sort: <field>` в заголовке                       |
| Группировка по сериям | `:group`                                   | остаёмся                                   | `[frame]` заголовки серий `Name (N)`                        |
| Recent                | `R`                                        | view=recent                                | `[frame]` заголовок Recent; фильтр сбрасывается             |
| Continue reading      | `C`                                        | view=continue                              | `[frame]` заголовок Continue reading                        |
| Палитра               | `ctrl+p`                                   | App-оверлей palette                        | `[frame]` модалка с командами и книгами                     |
| Help                  | `?`                                        | App-оверлей help                           | `[frame]` список клавиш                                     |
| Командная строка      | `:`                                        | Library `command`                          | `[frame]` промпт `:`, Tab-дополнение                        |
| Выход                 | `q`, `:q`                                  | выход из приложения                        | альтернативный экран закрывается, курсор мыши восстановлен  |

Пустая библиотека: `[frame]` «Library is empty.» + подсказка
«Attach a folder with :library add <path>…». Нет совпадений фильтра:
«No books match the current filter.» + «Press / to clear the filter.»
Пустой Continue: «No books in progress yet…».

### 1.2. Library — `filter` (промпт `/`)

| Действие    | Клавиша    | Переход  | Отклик                                                     |
| ----------- | ---------- | -------- | ---------------------------------------------------------- |
| Ввод текста | печатаемые | остаёмся | `[frame]` живой фильтр (debounce ~200 мс), курсор в начало |
| Подтвердить | `enter`    | `normal` | фильтр зафиксирован, `filter: "…"` в заголовке             |
| Отмена      | `esc`      | `normal` | фильтр возвращается к значению до открытия промпта         |

### 1.3. Library — `detail` (BookDetail)

| Действие         | Клавиша        | Переход                         | Отклик                                             |
| ---------------- | -------------- | ------------------------------- | -------------------------------------------------- |
| Читать           | `enter`        | reader                          | `[spinner] Opening book…` при синхронном парсинге  |
| Скролл аннотации | `j/k`, стрелки | остаёмся                        | `[frame]` текст прокручивается                     |
| Help             | `?`            | App-оверлей help поверх модалки | обложка скрывается, чтобы не перекрывать help      |
| Закрыть          | `esc`          | `normal`                        | `[frame]` модалка закрыта немедленно (forceRedraw) |

### 1.4. Library — `confirm-delete`

| Действие    | Клавиша     | Переход  | Отклик                                                                                                                                                                        |
| ----------- | ----------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Подтвердить | `y`/`enter` | `normal` | `[notify] Removed from library: …` или `Deleted file and library record: …`; при ошибке удаления файла — `Removed from library, but file delete failed: …`; курсор зажимается |
| Отмена      | `n`/`esc`   | `normal` | без изменений                                                                                                                                                                 |

### 1.5. Reader — `reading`

| Действие                 | Клавиша                        | Переход                                        | Отклик                                                                       |
| ------------------------ | ------------------------------ | ---------------------------------------------- | ---------------------------------------------------------------------------- |
| Скролл                   | `j/k`                          | остаёмся                                       | `[frame]` страница сдвигается; выделение мышью сбрасывается                  |
| Страница                 | `space`, PgDn/PgUp, `ctrl+d/u` | остаёмся                                       | `[frame]`; статус-бар `page N/M`, `%`                                        |
| В начало/конец           | `gg`/`G`                       | остаёмся                                       | `[frame]`                                                                    |
| Глава вперёд/назад       | `]`/`[`                        | остаёмся                                       | `[notify] Chapter: …` или `Already at the last/first chapter`                |
| Поиск                    | `/`                            | Reader `search`                                | `[frame]` промпт `/`                                                         |
| След./пред. совпадение   | `n`/`N`                        | остаёмся                                       | `[notify] Match X of Y` / `No search results`                                |
| Закладка                 | `b`                            | Reader `bookmark`                              | промпт `b `; при отсутствии книги в библиотеке — автосохранение через onSave |
| Список закладок          | `B`                            | Reader `bookmarks`                             | `[frame]` модалка                                                            |
| Оглавление               | `t`                            | Reader `toc`                                   | `[frame]` модалка                                                            |
| Инфо о книге             | `i`                            | Reader `info`                                  | `[frame]` модалка Book Info; обложка рисуется оверлеем                       |
| Зум картинки             | `z`                            | Reader `zoom` (если на странице есть картинка) | иначе `[notify] No image on this page`                                       |
| Упрощённый режим         | `:simplified`                  | остаёмся                                       | `[notify] Simplified mode: on/off`, переразметка                             |
| Выключка                 | `J`                            | остаёмся                                       | `[notify] Text justify: on/off`                                              |
| Широкий экран            | `W`                            | остаёмся                                       | `[notify] Wide screen: on/off`                                               |
| Сохранить в библиотеку   | `s`                            | остаёмся                                       | `[notify] Saved to library: <title>`                                         |
| Открыть файл             | `o`                            | reader (другая книга) / промпт                 | как в library                                                                |
| Палитра / help / команда | `ctrl+p` / `?` / `:`           | оверлеи                                        | как в library                                                                |
| Закрыть книгу            | `q`, `esc`                     | library                                        | прогресс сохранён, сессия закрыта (`ended_at`), список обновлён              |

### 1.6. Reader — модалки и промпты

| Режим           | Открытие        | Закрытие                                     | Особенности                                                                                                             |
| --------------- | --------------- | -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `search`        | `/`             | `enter` — выполнить, `esc` — сбросить запрос | `[notify] N matches · n/N to navigate` / `No matches found`; `esc` очищает поиск                                        |
| `command`       | `:`             | `enter` — выполнить, `esc` — отмена          | Tab-дополнение, подсветка валидного префикса                                                                            |
| `bookmark`      | `b`             | `enter` — сохранить, `esc` — отмена          | метка по умолчанию — выделенный текст; `[notify] Bookmark added` / `Cannot save bookmark: book not in library`          |
| `toc`           | `t`             | `esc`/`q`                                    | `j/k` курсор, `space` — развернуть/свернуть главу, `enter` — прыжок (`[notify] → <label>`), `/` — фильтр                |
| `toc-filter`    | `/` в toc       | `enter` — применить, `esc` — сброс           | плоский список совпадений                                                                                               |
| `bookmarks`     | `B`             | `esc`/`q`                                    | `enter` — прыжок (`[notify] Jumped to bookmark …`), `e` — правка метки, `d`/`x` — удалить (`[notify] Bookmark deleted`) |
| `bookmark-edit` | `e` в bookmarks | `enter`/`esc`                                | `[notify] Bookmark updated`                                                                                             |
| `info`          | `i`             | `esc` (back)                                 | `?` — help поверх                                                                                                       |
| `zoom`          | `z`             | `esc` или `z`                                | увеличенная картинка по центру                                                                                          |

Инвариант: повторное открытие любой модалки → `esc` закрывает (исторический
баг с гонкой useInput; регресс-тесты в `ReaderView.test.tsx`).

| Режим                           | Действия                                                              | Переход                                 | Отклик                                                          |
| ------------------------------- | --------------------------------------------------------------------- | --------------------------------------- | --------------------------------------------------------------- |

| `browsing`                      | `j/k`, `enter/l` — открыть запись/подраздел, `h` — назад              | внутрь фида / `entry-detail`            | `[frame]`; фасеты открывают подфид                              |
| `browsing`                      | `d` — скачать                                                         | остаёмся                                | `[notify]` от очереди; статус-бар `↓ N% title (+M)`             |
| `browsing`                      | `x` — панель загрузок                                                 | `downloads`                             | `[frame]`                                                       |
| `browsing`                      | `n`/`p` — след./пред. страница фида                                   | `loading` → `browsing`                  | `[frame]` `page X/Y`                                            |
| `browsing`                      | `/` — поиск                                                           | `search` → `loading` → `browsing`       | нет OpenSearch → `[notify] No search available in this catalog` |
| `browsing`                      | `c` — список каталогов                                                | `catalog-list`                          | позиция фида сохраняется                                        |
| `browsing`                      | `u`/`h`/`esc` — назад                                                 | предыдущий фид / `catalog-list` / выход | позиция курсора восстанавливается                               |
| `entry-detail`                  | `enter/d/l` — скачать                                                 | остаёмся                                | спиннер `Downloading` под карточкой                             |
| `entry-detail`                  | `esc/h`                                                               | `browsing`                              |                                                                 |
| `downloads`                     | `j/k`, `enter` — открыть скачанную, `d` — отменить, `x/esc` — закрыть | reader / остаёмся                       | `[notify] Downloaded: …` / `Download failed: …`                 |
| `error`                         | `esc`                                                                 | назад (browsing/catalog-list)           | `[frame] Error: <msg>` + подсказка                              |
| `auth-username`/`auth-password` | ввод, `enter`, `esc`                                                  | `loading` → `browsing` / `catalog-list` | креды сохраняются в БД; отмена на этапе пароля сбрасывает имя   |

### 1.8. Глобальные / фоновые

| Событие                        | Поведение                                     | Отклик                                                                             |
| ------------------------------ | --------------------------------------------- | ---------------------------------------------------------------------------------- |
| `:library add <path>`          | attach + скан                                 | `[notify] Attached folder: …` → `Scanning …: k/N` → `+N new, M updated, K removed` |
| `:library scan`                | полный рескан                                 | то же; при повторном запросе — `A library scan is already running; queued`         |
| `:library remove <path>`       | confirm-модалка                               | `[notify] Detached …; removed N books`                                             |
| Вход в library                 | авто-рескан «грязных» папок (mtime)           | тихо, если чисто; иначе прогресс скана                                             |
| SIGINT/SIGTERM/SIGHUP          | flush прогресса + закрытие сессии + выход     | альтернативный экран закрывается, оверлеи убиты                                    |
| Resize терминала               | переразметка ридера; рестарт оверлея картинок | `[frame]`                                                                          |
| `:theme <name>` / theme picker | смена темы                                    | preview в пикере; `[notify] Theme: <name>`; персист в конфиг                       |
| Неизвестная тема               | fallback                                      | `[notify] Unknown theme "…", using default`                                        |

## Часть 2. Сквозные сценарии (journeys)

Каждый journey — путь по матрице; шаги проверяются интеграционным тестом
через полный `App` (реальный `LibraryDb` в tmp, реальные fb2-фикстуры,
замокан только OPDS-HTTP).

### J1. Первый запуск → знакомство

1. Пустая библиотека → empty-state с подсказкой. _(1.1)_
2. `:library add <tmp>` → «Attached folder» → прогресс скана → «+N new». _(1.8)_
3. Книги в списке; `j/k` курсор; `enter` → карточка. _(1.1, 1.3)_
4. `enter` в карточке → чтение. _(1.5)_
5. Несколько страниц, `q` → библиотека, recent обновлён. _(1.5)_

### J2. Возвращение читателя

1. Перезапуск App на той же БД.
2. `C` → Continue reading показывает книгу с процентом. _(1.1)_
3. Открытие → позиция восстановлена (goToCharOffset). _(1.5)_

### J3. Обслуживание библиотеки

1. `:library add` второй папки → скан. _(1.8)_
2. `:library remove <первая>` → confirm → «Detached…; removed N books»,
   книги исчезли, файлы на диске целы. _(1.8)_
3. Повторный `:library add` той же папки работает.
4. `:library scan` на пустом списке → подсказка. _(1.8)_

### J4. Локальные файлы вне библиотеки

1. `:open <path>` → чтение без записи в библиотеку.
2. `s` → «Saved to library». _(1.5)_
3. `:open <битый файл>` → «Cannot open …», приложение живо. _(1.5)_
4. `o` без picker → path-промпт; `esc` → отмена без изменений. _(1.1)_

### J5. OPDS: обнаружение → скачивание → чтение

1. `:opds` → список каталогов (пустой → `:opds add`). _(1.7)_
2. Открыть каталог → spinner → browsing. _(1.7)_
3. Фасеты, подразделы, `n/p` пагинация. _(1.7)_
4. `/` поиск → результаты. _(1.7)_
5. `d` на двух книгах → очередь, статус-бар `↓ …`, панель `x`. _(1.7)_
6. `d` в панели — отмена; завершившаяся книга — `enter` → чтение. _(1.7)_
7. Книга появилась в библиотеке (db.addBook из очереди загрузок).

### J6. Смешанный день

1. Чтение локальной книги → `q`.
2. OPDS: скачать книгу → открыть из downloads → несколько страниц → `q`.
3. Библиотека: обе книги с корректным раздельным прогрессом; Continue
   показывает обе.

### J7. Прерывания и внешние события

1. SIGTERM во время чтения → прогресс и сессия записаны (нет строк без
   `ended_at`), процесс завершён.
2. SIGINT в библиотеке → чистый выход.
3. Resize в ридере → переразметка без потери позиции.
4. Быстрый ввод чанками (`t\u001b` одной записью) → модалка открылась и
   закрылась. _(1.6)_
5. Повторное открытие модалок → `esc` работает. _(1.6)_

### J8. Инвариант обратной связи (сквозной)

Для каждого async-действия из матрицы: есть видимый отклик (spinner/notify/
статус-бар); ошибки читаемы; notify исчезает (~3.5 с); статус-бар отражает
режим (SEARCH/COMMAND/LOADING/ERROR/DOWNLOADS).

## Часть 3. Кандидаты на баги (проверяются в Этапе 4)

1. **`DeleteConfirm` / `BookDetail` — собственный `useInput`.** В ReaderView
   гонку useInput чинили переходом на один always-on `useInput` + ref
   (см. комментарий в ReaderView.tsx). Здесь паттерн не применён — возможен
   «проглоченный Esc» при повторном открытии подтверждения удаления.
2. **`keymap.feed()` и префиксные комбо.** Клавиша, являющаяся и одиночной
   привязкой, и префиксом комбо (`g` в `gg`), срабатывает сразу и остаётся в
   буфере последовательности — риск двойного срабатывания.
3. **Двойной `saveProgress`** при закрытии ридера: `flushSession()` в
   `closeReader` + cleanup-effect по `session` в App.
4. **Хрупкие офсеты мыши** (`y-2`, `x-2`) в ReaderView/LibraryView —
   зафиксировать тестами hit-testing.
5. **`hintBar` в LibraryView** — параллельные массивы `items`/`actionsList`
   (индексная рассинхронизация при правках).
